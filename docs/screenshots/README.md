# Screenshots

Add at least one real TREK planner screenshot before registry publication.

Recommended capture:

- Open a TREK 4.x instance with the Waterway plugin installed and enabled.
- Open a trip day with two or more places near a waterway.
- Select the `Waterway` route profile in the day-plan route picker.
- Capture the planner showing the route profile and rendered route.
- Save it here as `waterway-route-profile.png`.

Do not use live Overpass screenshots as a required CI artifact. They are useful for
registry review and release notes, but deterministic fixture tests remain the release
gate.
